# Ops Hub — Local Operations Dashboard

Local-first CRM/ERP dashboard for brands running on **Deku**. This repo ships with **Finecoustic** as the example brand (`brands/finecoustic/`). Boss-ready charts and tables; edit stock inline or ask Koji to update data.

## Quick start

```bash
node ops-hub/server.mjs
```

Open http://localhost:3456

The server serves the UI **and** saves edits to `brands/finecoustic/ops-data.json`.

## Workflow

| Who | Does what |
|---|---|
| **You** | View dashboards; quick-edit stock on Inventory tab |
| **Koji** | Bulk updates, B2B orders, Shopify sync, hub changes |
| **Host assistant** | General tasks, setup, cross-project help — not ops system of record |

## Data

| File | Purpose |
|---|---|
| `brands/finecoustic/ops-data.json` | System of record |
| `brands/finecoustic/shopify-snapshot.json` | Generated by Shopify sync (gitignored) |

**Stock categories:** B2B · Personal · **Unknown** (untracked) · On hand (Dongguan)

## Shopify sync

```bash
node ops-hub/sync/shopify-pull.mjs finecoustic
```

Requires Shopify CLI auth in `shopify/`.

Say **"Koji, …"** for inventory, B2B logging, or hub work.
