## Hard rule for Senku competitive work

When mapping competitors for **Hako Studio 301/302** (or any compact active desktop/bookhelf SKU), run **all three lanes** before delivering a comp set:

1. **Design-first desktop** — Kanto (YU2, UKI, ORA), Audioengine A2+, Creative desktop actives, Argon STUDIE (near-size), Vanatoo (near-size), Cambridge L/R S
2. **Studio / reference compact** — Edifier MR/M60, PreSonus Eris, M-Audio BX, IK iLoud Micro, AT-SP3X
3. **OEM / white-label** — Saiyin, Sanyun, etc. (separate tier; label clearly)

**Search terms to always run:** `Kanto YU2`, `compact desktop powered speakers 3 inch USB sub`, `design desktop speakers sub out optical`, plus category leader brands by name.

**Do not** rely on generic "bookshelf speaker under $100" queries alone — they over-index studio monitors and Amazon OEM.

**Output requirement:** Separate tables for (a) exact 3″ woofer, (b) near-size design desktop (2.75–3.5″), (c) OEM. Flag closest **positioning** peer even if not closest spec peer.
