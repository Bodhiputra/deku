**Hard rule:** Finecoustic typography is **Alte Haas Grotesk** — sole typeface, all weights, all contexts. Canonical source: `context/design-context.md` → Typography.

**Never say or brief:**
- "Grotesque sans"
- "Clean grotesque" / "any grotesque substitute"
- Space Grotesk, Inter, Helvetica, or other stand-ins **as brand typography**

**KOL / creator briefs:** If on-screen text is needed, specify **Alte Haas Grotesk only**. Offer to share the font file. Most creator content has no type overlays — only mention when relevant.

**Figma exception (technical only):** When `loadFontAsync` fails for local Alte Haas Grotesk inside Figma Plugin API, Space Grotesk may be used **only as a temporary Figma editing workaround** — never as the stated brand typeface in briefs, exports, or handoffs to creators.
