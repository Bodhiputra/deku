# Industry Context — Template

Copy to `context/industry-context.md` (gitignored) or let Senku create via `industry-onboarding`.

```yaml
brand_slug: your-brand
industry_slug: your-industry-slug
industry_label: Human Readable Industry Name
bank_path: knowledge-bank/brands/your-brand/your-industry-slug/
bank_maturity: seeded
assigned_date: YYYY-MM-DD
last_deep_dive: null
notes: |
  Optional notes.
```

## Example — Finecoustic

```yaml
brand_slug: finecoustic
industry_slug: consumer-portable-audio
industry_label: Consumer Portable Audio
bank_path: knowledge-bank/brands/finecoustic/consumer-portable-audio/
bank_maturity: seeded
assigned_date: 2026-06-08
last_deep_dive: null
notes: |
  Primary vertical: portable Bluetooth speakers and related consumer audio.
  Services: none. Physical products only.
```
